# ПР3. Ответы на контрольные вопросы

1. `x += 5;` — сокращённая запись `x = x + 5;`. Результат в памяти одинаковый:
   переменная увеличится на 5. Разница только в форме записи — составные
   операторы короче и читаются легче.

2. `x++` сначала отдаёт в выражение старое значение, потом увеличивает
   переменную. `++x` сначала увеличивает, потом отдаёт новое значение.
   При `int x = 1;` строка `Console.WriteLine(x++)` выведет 1,
   а `Console.WriteLine(++x)` выведет 2. Отдельной строкой разницы нет.

3. Всегда `bool` — то есть `true` или `false`.

4. Короткое замыкание — C# не вычисляет второй операнд, если результат уже
   известен: в `&&` при левой части `false` правая не проверяется, в `||`
   при левой `true` — тоже. Пример: `if (n != 0 && sum / n > 10)` — вторая
   часть не выполнится при n == 0, поэтому деления на ноль не произойдёт.

5. Сначала `*` и `/`, потом `+` и `-`, слева направо:
   10 - 2 _ 3 + 4 / 2 = 10 - 6 + 2 = 6. Проверка кодом:
   `Console.WriteLine(10 - 2 _ 3 + 4 / 2);` выводит 6.

6. Скобки делают порядок вычислений очевидным для того, кто читает код:
   не нужно помнить таблицу приоритетов, и меньше шанс ошибиться,
   когда выражение позже изменят.
